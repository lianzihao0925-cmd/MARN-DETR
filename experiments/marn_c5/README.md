# C5：原型内容贡献诊断

`diagnose_content.py`：在上一轮 MARN regular 权重上比较真实原型、关闭修正、打乱特征和打乱类别四种冻结推理干预，使用完整 COCO val2017、maxDets=100。只写诊断目录，不修改训练源码和原权重；比较不能替代重新训练的消融。

远程部署位置：`experiments/marn_c5/`。`content_diagnostic/` 中 JSON 和日志是小型审计证据，应保留；脚本与说明一起保留，已有完整 ZIP 归档后可删重复上传副本。本阶段不生成新权重。诊断使用已有模型与训练集原型，验证集目标仅用于评价。

本阶段用户授权截止北京时间 2026-10-18 06:00，新增 GPU 工作累计最多 4 小时。诊断会受到 20 分钟超时限制；实际耗时计入本阶段预算。

`probe_router.py`：离线收益路由试验。冻结现有检测器和记忆，每张训练图比较上下文集合 S 与 S 加一个探索查询；采用参考分支固定 Hungarian 匹配下的官方分类/框损失差作为标签。每图两个探测，75% 从前60个预测探索，25% 全查询探索。按图像划分路由训练/留出集。只在留出集 MSE 比常数预测降低至少2%且相关系数大于0.05时进行完整验证集评价。此为离线 UAMR 试验，尚未复用前段网络，也不是在线联合训练的完整 UAMR。

`router_smoke/`：8张训练图的接口、确定性与状态冻结检查，验收后可删除缓存；保留结果 JSON/日志。`router_pilot/`：4096张训练图、8192个单查询收益样本；`train_probe_examples.pt` 是小型训练缓存，路由实验归档后可删，`router.pt` 是单独路由权重及归一化元数据，应随脚本和结果保存。它不能单独替代完整检测器权重，未通过留出门槛时不得宣称路由有效。

`frozen_module.py`：冻结官方检测器全部参数，只训练83,460个adapter参数；supervised分支在原检测损失外加入0.05倍类别检索监督。监督仅来自插入层第一训练组的可靠匹配对象；bank停止梯度，键映射保留梯度，无有效正负原型时安全零损失。它是独立模块，不覆盖已安装源码。

`run_frozen_arm.py`：复用C4官方训练/评价/原子保存及数据哈希框架，官方权重初始化，adapter学习率1e-4、其余参数冻结；10轮余弦日程中只跑1轮。包括冻结参数哈希、有限梯度、adapter实际更新检查。与早先全模型微调协议不同，结果必须单列。

`run_frozen_pair.py`：依次运行query-only、原MARN、带检索监督MARN三个分支，统一seed42、相同初始化及数据次序；核对参数哈希和输入哈希，不自动重试。`--smoke`每分支4训练批/2验证批、总10分钟；正式筛选每分支1完整epoch、总2小时。服务器硬截止不会晚于2026-10-18 06:00。三个分支总墙钟计入新增4 GPU小时。

`frozen_smoke/`内checkpoint是工程测试临时产物，结果与源码完整归档且通过后可删；日志/JSON保留。`frozen_screen/`为新协议正式单种子筛选，checkpoint与推理权重暂保留；仅下载小型指标、日志、配置和哈希，不下载完整检测器权重。
