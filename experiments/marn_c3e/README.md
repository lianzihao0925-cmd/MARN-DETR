# C3E：减少原型写库中的同步

用途：验证并应用写库的等价优化，再复用原 C3C 三组配对协议测速。远程目录为 `experiments/marn_c3e/`。由助手执行；不要额外重跑训练。

优化只涉及 `MARNAdapter.commit`：每步一次读取离散类别/有效性元信息，在 CPU 维护本步有效槽位索引，并将相似度和替换优先级的小型结果一次性取回。浮点相似度、优先级、更新算式、候选全局排序、同类顺序、替换规则和写入来源均保持原定义。查询数量、原型容量、损失、增强和 EMA 政策不变。

`check_commit.py` 在安装前比较 CPU、CUDA FP32、CUDA BF16 下的旧/新实现，覆盖连续窗口、填充/更新/替换、相似度阈值、并列最大值、NaN 行为、空候选和严格状态重载。要求状态和统计逐项精确一致。它不需要检测器或 COCO 训练，不修改源码。

| 文件 | 用途及覆盖行为 | 删除时机 |
|---|---|---|
| `integration_candidate.py` | 待验证的接入模块；单纯上传不会安装 | 正式版本保留；失败候选可删 |
| `check_commit.py` | 旧/新写库精确对照 | 随版本保留 |
| `source_guard_original.json` | 记录被替换前的已验收源码哈希 | 随版本保留 |
| `commit_check_result.json` / 测试日志 | 安装前等价性证据 | 保留 |
| `install_and_launch.py` | 安装前核对旧版哈希、备份并原子替换实现，然后启动回归；当前服务器已经安装并验收，不要重复安装 | 随版本保留 |
| `launch_benchmark.py` | 在独立目录复用原 C3C 协议，启动三组配对测速 | 已完成测速；随版本保留，不需要重跑 |
| `source_guard_optimized.json` | 优化后安装源码的哈希，供正式训练预检 | 正式运行依赖，保留 |
| best/last 以外的短测试权重 | 仅验证恢复，不能作为正式初始化 | 确认对应检查通过后可删 |

安装前必须保留原文件备份；安装只原子替换已检查的 `marn/integration.py`。旧 C3C 结果及源码哈希保留，新测速使用单独目录与新 guard，不改旧报告。实际是否提速须以新的无 profiler 三次配对测量为准。

当前安装和回归已完成。三次配对复测中，MARN 为 80.4724 ±0.9029 张/秒，Baseline 为 108.2506 ±1.3095 张/秒；± 为样本标准差。MARN 一次低于 80，完整 epoch 时间尚待正式筛选确认。回归临时权重已归档证据后清理，保留 JSON 和日志。
