# MARN-DETR C1：核心算子验收

本包在独立目录中运行，不覆盖 RF-DETR 源码、不加载检测器权重、不使用 COCO 图像、不启动训练。

已实现：按类预留槽位的原始特征与元数据存储、独立快照、仅对选中查询进行原型检索、候选拒绝、T=1 有界 MGQR。正式写库流程尚未实现；check_core.py 中的手动填充仅是合成测试数据。

检索使用共享可学习键投影（查询和原型共用，初始化为截取单位映射）；类别项由真实 category ID 对应的 sigmoid 分数归一化得到；几何项只比较宽高，不比较跨图绝对位置。支持 top-k、质量和年龄项，没有 top-1 类别硬过滤。

MGQR 使用 LN(q)、LN(m)、逐元素乘积和检索摘要，经过窄瓶颈与零初始化输出投影。残差范数上限 rho * ||q||；独立门控上限 beta_max，只乘一次。无候选或未选中的查询旁路。

默认起点（不是经实验选出的最佳值）：每类 4 个槽位、键维度 64、top-k=4、温度 0.2、类别/几何/质量/年龄权重 0.2/0.1/0.2/0.1、年龄尺度 1000 更新步、余弦拒绝阈值 0、瓶颈 64、rho=0.1、beta_max=0.5。未来正式实验前应与写库阈值、冷启动日程一起固定。该模块本身不设路由预算；后续由选择器按每个训练组的相同语义提供 selected mask。

## 运行

在 AutoDL 的 marn-detr 环境中执行：

```bash
python -u check_core.py
python collect_integration_context.py
```

check_core.py 使用合成张量验证 CPU FP32 和可用时的 CUDA BF16：空库旁路、零输出恒等、快照独立性、无效 NaN 槽位、连续两步梯度、未选查询不变、残差范数约束、候选拒绝、只读评估和状态保存恢复。

合成测试通过不等于完整检测器等价性、检测精度提升或性能验收通过。后续 C2 必须接入真实匹配结果、同图同 GT 跨组去重、质量/新颖性写入、优化器步末提交、快照生命周期、EMA 与 bank 保存恢复，并检查完整 forward/loss 的禁用等价性。

预定插入点：TransformerDecoder 第 1 层（layer_id=0）完成原有 reference 更新和 intermediate 记录之后、第 2 层之前。仅修正传向下一层的 output，不重写已记录的第 1 层输出或 reference 更新规则。写库特征必须来自该插入点修正前的同层 output。

## Baseline 已知结果

- 固定 512、BF16、COCO val2017、maxDets=100、seed=42。
- 初始官方权重 AP：52.9224038124。
- 十轮最佳普通模型 AP：52.7680695057（第 1 轮），比初始低 0.1543343067 AP 点。
- 十轮最佳 EMA AP：52.7376115322（第 6 轮）。
- 最后一轮普通模型 AP：52.7436554432。
- 十轮耗时 11547.9063 秒（3.20775 GPU 小时），峰值已分配显存 9.0358 GiB。
- 正常退出，十轮完整、73930 次更新，所有观测 loss 有限。

后续受控实验从同一官方权重独立初始化，保留初始权重和同预算训练 Baseline 两条参照。当前结果不支持微调提升、充分收敛或多种子稳健性的结论。APS/APM/APL 等完整报告项尚待补齐。
